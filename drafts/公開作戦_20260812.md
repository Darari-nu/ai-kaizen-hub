# 公開作戦 — 記事とSubstackの出し方・順番・スケジュール（2026-08-12策定）

darari依頼「どのように公開するか？作戦考えて順番も。スケジュールも。サブスタックの公開も含めて」への回答。
大原則は既定方針のまま: **HPは倉庫、Substackが本丸。全ページからSubstack登録に誘導する。**

## 作戦の3本柱

1. **一気に全部出さない。** 検品OKが出た記事から、週2本ペースで固定曜日（火・金）に出す。
   理由: ①Substackの配信ネタが毎週続く ②検品ペースと無理なく同期 ③検索エンジンにも自然な更新頻度
2. **記事公開とSubstack通達を2段ロケットにする。** 記事をHPに置く→その配信版を通達としてSubstackで流す。
   1本のネタが2回働く。通達は「今週のダラリ重工業」として金曜固定
3. **公開の絶対条件は「darariの検品OK」。** OKが出ていない記事は日程が来ても飛ばす（スケジュールが後ろにズレるだけ。品質は落とさない）

## 公開作業の運用（毎回ぼくがやること）

1. 公開前チェック: 公開する記事の中に「まだdraftの記事へのリンク」「ボツ記事へのリンク」がないか機械チェック
2. `draft: false` → push（Cloudflareが自動デプロイ、1〜2分）
3. 本番URLで表示・OGPカード確認（XやDiscordに貼ってカードが出るか）
4. 通達の下書きを検品室に積む（配信版は毎回ぼくが起こす）
