「作ったページを公開したいだけなのに、サーバー代って毎月かかるの？」

そう思ったこと、ありませんか？

レンタルサーバーは月1,000円くらいから。制作会社に頼めば数十万円。予約システムなんて、初期3万円＋月1.3〜2.1万円という料金表をぼくは見たことがあります。

見た瞬間、思いました。「これ、自分で作れるのでは？」

結論から言い切ります。**見せるためのページなら、無料で公開できます。**

ぼくはエンジニアではありません。製造業の中の人です。それでも、このサイト自体を無料で公開しています。月額0円。クレジットカードの登録もなしです。

## そもそも「デプロイ」って何？

むずかしい言葉から片付けましょう。

**デプロイ**とは、作ったものを「みんなが見られる場所に置く」作業のこと。※家で書いた回覧板を、掲示板に貼りに行くようなものです。

その「置き場所」が**サーバー**。※24時間動きっぱなしのコンピュータで、誰かがアクセスしてくるとページを見せてくれる係です。

「じゃあそのサーバーを借りるのにお金がかかるんでしょ？」

そこなんです。実は、無料で貸してくれる場所があるんですね。

## ぼくが使っているのは GitHub Pages

**GitHub**※は、世界中の開発者がプログラムやファイルを置いている保管サービスです。Microsoftが運営しています。

そのGitHubには **GitHub Pages** という機能があって、置いたファイルをそのままホームページとして公開できます。無料で、です。

やることは3つだけ。

1. **AIにページを作ってもらう**（ChatGPTやClaudeに「こういうページのHTMLを作って」でOK）
2. **GitHubにファイルを置く**
3. **設定画面でPagesをオンにする**

これで世界中に公開されます。…。マジか！と最初は思いました。

ぼくの実例をひとつ。趣味で作った自動集計ツールを、手元のWindows PCで動かそうとしたことがあります。Celeron・メモリ4GB・HDDのポンコツです。重すぎて動きませんでした。

それをGitHubの自動実行機能※に載せ替えたら、ポンコツPCの出番ゼロで動き続けています。費用は完全無料。無料枠が月2,000分あるうち、使っているのは1,200分くらいです。※GitHub Actionsという、決めた時間に作業を自動でやってくれる機能です。

## ぼくの失敗談：全部AI任せにして、攻撃され放題

とはいえ、ぼくも最初から無料一本だったわけじゃないんです。

昔、月額のVPS※を借りたことがあります。※自分専用の小さなサーバーを借りるサービスです。自由度が高いぶん、守りも全部自分の仕事になります。

セキュリティ設定をClaude（AI）に全部任せました。「AIがやってくれるなら安心でしょ」と。

結果、スパム攻撃され放題でした。。。

さらに設定をいじっていたら、自分がログインできなくなりました。自分のサーバーから締め出されるという、なかなかの体験です。最終的に、自分のPCからしか入れないよう設定し直してようやく落ち着きました。

もうひとつ白状します。公開・非公開の設定を間違えて、非公開にするつもりのファイル置き場を約10時間、世界に公開していたこともあります。

この2つの失敗から言えることは、こうです。

**見せるだけのページに、VPSは要りません。** GitHub Pagesなら、攻撃されて困る「自分のサーバー」がそもそも存在しないんです。守る仕事ごと消える。これが無料より効くポイントなんですね！

ただし「公開・非公開の確認」だけは、AI任せにせず自分の目でやってください。ぼくとの約束です。

## 情シスに聞かれたときの想定問答

会社のPCで試したい人のために、聞かれがちな質問と答え方を置いておきます。

**Q1.「それ、会社の情報を外に置くことになりませんか？」**

なります。だから会社の情報は1文字も入れないでください。練習は個人のアカウント・個人のPCでやる。これが鉄則です。

**Q2.「GitHubって安全なんですか？」**

Microsoftが運営していて、世界中の企業が業務で使っています。ただし公開・非公開の設定は自分の責任です。ぼくの10時間事故を思い出してください。

**Q3.「費用はどう処理するんですか？」**

0円です。稟議書に金額欄がないレベルの話なので、個人の学習として始める分には処理するものがありません。

**Q4.「業務で使いたいんだけど？」**

そこからは正規ルート、つまり会社への申請の話になります。勝手に入れるのはやめましょう。申請の通し方こそ、このサイトでずっと実況していくテーマです。

## できない場合の逃げ道

「会社のPC、GitHubがブロックされてた」——ありますよね。家のPCかスマホで練習しましょう。個人の学習を会社の設備でやる必要はないです。

「そもそも公開するのが怖い」——わかります。その場合、作ったHTMLファイルを自分のPCで開くだけでも動きます。公開はいつでもいい。作る練習が先です。

## 今日の一歩

やることは1つだけ。**GitHubの無料アカウントを作る。** それだけです。

サーバー代の請求は、来ません。ぼくが毎月払っているのは0円です。
