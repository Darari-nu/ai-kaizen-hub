毎月、あの日が来ます。

各部署から集まったExcelを開いて、コピーして、貼り付けて、集計して、体裁を整える。

気づいたら夕方。今月も1日仕事です。

「しかもこれ、間違えられないんだよな……」

そうなんです。単純作業のくせに、集中力だけは要求してくる。いちばん疲れるタイプの仕事ですね。

こんにちは、だらリーヌです！

ぼくは製造業のJTC企業で、製造部門のAI活用推進を担当しています。職場ではClaude Teamを7名で導入して、日々の業務をAIでカイゼンしています。

今日は、毎月の手作業集計の話です。

言い切ります。**その集計、来月からは「手順を書く仕事」に変わります。**

毎月手を動かすのではありません。手順を1回だけAIに書かせる。来月からは、実行して、結果を確認するだけです。

## そもそも、なぜ毎月同じ作業をしているのか

毎月の集計って、よく考えると変なんです。

ファイルの形式は毎月同じ。やる手順も毎月同じ。同じ手順の繰り返しは、機械がいちばん得意なことです。

なのに人間がやっている。理由はひとつで、**手順をプログラムにできる人が職場にいなかったから**です。

いまは違います。プログラムはAIが書きます。あなたがやるのは「何をどう集計したいか」を日本語で説明することだけです。

> **ことばメモ｜プロンプト** AIへの指示文のこと。この記事では、コピペしてそのまま使えるプロンプトの例を3つ載せています。

## やってみた: 道具の階段は3段です

難しい方に行くほど強力です。でも、非エンジニアは1段目からで大丈夫です。

### 1段目: AIに貼って聞く

表をそのままAIに貼って、「この形式で集計して」と頼む方法です。登録も設定も要りません。

```
この表を、担当者ごとに集計してください。
・列は「担当者」「件数」「合計金額」の3列
・合計金額が大きい順に並べてください
最後に、全体の合計金額も出してください。

（ここに表を貼り付け）
```

これだけで、集計とレイアウトまで返ってきます。

ただし弱点があって、**来月もまた貼る必要があります**。それと、貼っていいデータかの確認が先です。これはあとで書きます。

### 2段目: AIに関数・数式を書かせる

「この列とこの列を突き合わせて、条件に合う行だけ数えたい」

こういう集計、VLOOKUPやCOUNTIFS（条件に合う行を数えるExcel関数）が組めれば一瞬なんですが、組める人が少ない。だからAIに組ませます。

```
Excelの数式を作ってください。
・シート「売上」のB列に担当者名、E列に金額が入っています
・シート「名簿」のA列にいる担当者だけを対象に、
　金額が10万円以上の行の数を数えたいです
貼り付ける数式をそのまま出してください。
数式の意味も、1行ずつ日本語で説明してください。
```

1段目との違いは、**式がファイルに残ること**です。

来月は、新しいデータを貼れば式が勝手に計算します。もうAIに聞き直す必要すらありません。

### 3段目: AIに集計プログラムを書かせる

最終形です。毎月ファイル名だけ変えて実行すれば終わる状態にします。

```
毎月のExcel集計を自動化するプログラムを、Pythonで書いてください。
・フォルダに「売上_202608.xlsx」のような名前のファイルが毎月増えます
・指定した月のファイルを読み込み、「部署」ごとに「金額」を合計してください
・結果は「集計_202608.xlsx」という名前で、同じフォルダに保存してください
・実行するのはプログラムに詳しくない人です。
　実行の手順も、日本語で1から説明してください
```

Python（無料で使えるプログラミング言語）と聞くと身構えますよね。でもコードを書くのはAIです。

あなたの仕事は2つだけ。「何をどう集計したいか」を日本語で説明すること。そして、動かして結果を確認することです。

ぼくは実際に、ポンコツPC（Celeronでメモリ4GB）でも動く自動集計を作りました。集計プログラムはゲームと違って軽いので、職場の古いPCでも動きます。

エラーが出たら、そのエラー文をコピーしてAIに貼るだけです。「直しました」と修正版が返ってきます。

## 貼る前に: そのデータ、外に出していいですか

ここ、この記事でいちばん大事です。

毎月の集計ファイルには、顧客名・取引先名・未公開の数値が入っていることが多い。**それをそのまま外部のAIに貼るのは、アウトの会社が多いです。**

うちの会社のAI利用は「申請すれば使える」制度です。あなたの会社のルールがどうなっているかを、先に確認してください。何を確認すればいいかは[入れていい情報のルール](/articles/002-ai-rules-starter/)にまとめています。ダラリ重工業の[AI利用規程](/company/ai-kitei/)みたいに、情報をレベル1・2・3で区分している会社なら、自分のデータがどのレベルかを見るだけです。

そして、ルール的に貼れないデータでも、逃げ方があります。

- **固有名詞を伏せる**: 顧客名を「A社」「B社」に置き換えてから貼る
- **数値をダミーにする**: 金額を適当な数字に差し替えた表で、手順だけ作らせる。**数式もプログラムも、中身がダミーでも同じものができます。** できた手順を、本物のデータに社内で当てるだけです

集計の手順に、機密は含まれません。だから「手順を書く仕事」は、データを外に出さずにできるんです。

## 失敗談: 検算せずに出しかけました

かっこ悪い話をします。

AIに作らせた集計結果を、そのまま報告に使いかけたことがあります。

出す直前に、念のため元の表の合計と突き合わせたら、数字が合わない。冷や汗が出ました。

原因はAIではなく、ぼくの説明でした。集計から除きたい行があったのに、それを伝えていなかった。AIは言われたとおりに、全部の行を足していました。

この経験からの教訓はひとつです。**生成AIは間違えることがある。これはバグではなく仕様です。**

だから、AIが出した集計は、必ず1回は自分で検算する。合計が元データと合っているかを見る。この確認までが工程です。

逆に言うと、3段目まで行けば検算はラクになります。プログラムは一度正しく動けば、来月も同じ動きをするからです。毎月ゼロから検算するのは最初だけです。

## 想定問答: これ、聞かれます

**Q1.「会社のデータをAIに貼っていいの？」**

会社によります、で終わらせません。確認する場所は決まっています。AI利用のルールと、情報の機密区分です。ルールが見当たらないなら、[この記事](/articles/002-ai-rules-starter/)の3点を情シスに聞いてください。それまではダミーデータで手順だけ作るのが安全です。

**Q2.「会社のPCにPythonなんて入れられないんだけど」**

なら2段目までで戦えます。Excelの数式は、どの会社のPCにも最初から入っています。3段目に行きたくなったら、情シスに「集計の自動化に使いたい」と申請しましょう。堂々と便利になるのが正規ルートです。

**Q3.「マクロ（VBA）と何が違うの？」**

やりたいことは同じです。あなたの会社がVBAなら動かしやすいなら、AIへの頼み方を「Pythonで」から「ExcelのVBAで」に変えるだけです。大事なのは言語ではなく、**自分でコードを書かないこと**です。

**Q4.「AIが集計を間違えたら責任問題では？」**

間違える前提で工程を組みます。検算してから出す。これは人間の部下に集計を頼むときと同じですね。確認せずに出したら、それは頼んだ側の仕事の抜けです。

**Q5.「毎月、ファイルの形式が微妙に変わるんだけど」**

あるあるですね。変わったら、またAIに「列が1本増えたので直して」と頼むだけです。修理も日本語でできるのが、この方法のいいところです。

## AIに貼れない・PCに何も入れられない人へ

全面禁止の会社でも、できることがあります。

**データを1行も貼らずに、構造だけ説明する**方法です。

「A列に日付、B列に部署名、E列に金額が入った表があります。部署ごとに金額を合計する数式をください」

これなら、外に出ているのは列の並びだけです。機密は1文字も出ていません。

それと、集計の元データを社内システムから落とす操作が分からないときは、画面をAIに見せて聞くワザがあります。[別の記事](/articles/008-shanai-system/)で深掘りしています。

## 今日の一歩

毎月いちばん憂鬱な集計ファイルを、ひとつ思い浮かべてください。

そして、データは貼らずに、列の構造だけをAIに説明して、数式を1本もらってみてください。

「え、こんな日本語で数式が返ってくるの」

その驚きが、手作業集計の引退届です。来月のあなたは、実行して確認するだけの人になっています！
