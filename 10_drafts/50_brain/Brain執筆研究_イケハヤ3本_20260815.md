# Brain執筆研究: イケハヤ3教材の型分析（2026-08-15）

- 対象: 『明鏡』（29,800円・手書き・約25万字）／『軍配』（980円・スキル配布型）／『シン・X攻略の教科書』（1,480円・書籍型）
- 目的: ダラリーヌBrain教材「会社のチャットボット自作の教科書」（2,980円）の文体・改行・構成の参考
- 注意: **型を借りる。文章は借りない**（文体はdarariの「ぼく」文体＝BRAND.md/RULES.mdが正本のまま）

## 1. 改行・文体の型（3本共通）

- **1文＝1〜2行で改行。段落は最大3文**。空行区切りが極めて多い。スマホ読み前提の縦リズム
  - → darariの「段落は20文字×3行が上限」ルールとほぼ同じ思想。**そのまま流用できる**
- 短文連打で畳みかけ、たまに長文で溜める。体言止め・一語文（「逆です。」「大丈夫です。」）で切り返す
- 読者の心の声を先取りして返す（「〜と思いましたか？その気持ちも分かります」）
  - → darariの文体ルールに**既にある**。Brainでも同じ型が最前線で使われている確認が取れた
- 専門語はゼロから説明してから使う（スキルとは/認証済みユーザーとは）→ darariの「※で即解説」と同思想
- 数字は必ず「実測＋時点明記」（例:「2026年8月時点の実測です」）→ 教材でも全数字にこれを付ける
- 「正直に書きます」「白状します」で弱み・事情を先に開示 → 信頼の演出。検証実況フレーミングと相性が良い

## 2. 販売ページ（無料部分）の構成テンプレ（3本に共通する順番）

1. 名乗り＋現在地（実績・立場を理由つきで先に開示。「誰が言ってるかがすべて」）
2. ひとこと要約（「ひとことで言うと——」）＋読者の毎日がどう変わるか（Before/After箇条書き）
3. 概念のゼロ説明（この教材の中心概念を素人語で）
4. 実演・実例（架空例でいいから「温度感」を見せる。概念名より具体的な会話例が先）
5. 中身の紹介（**章立てを全公開**。出し惜しみしない）
6. 特典
7. 向かない人・向いている人（向かない人が先）
8. FAQ（買わない理由に先回り）
9. 価格の理由を正直に語る（なぜこの値段か。値上げ予告は事実ベース）
10. 免責事項
11. 追伸（哲学・物語で締める）

## 3. 無料/有料の課金線の引き方（最重要の学び）

- 3本とも**無料部分が異常に厚い**。X教科書は第1章+第2章=1万字超をまるごと無料。「中身で判断してほしいから」と明言し、「読み終えて要らないと思ったら、そっと閉じてもらって大丈夫」とまで書く
- 課金線の直前に「ここまでが無料公開です」の明示ブロック → 有料側の各章予告 → 価格＋値上げ予告 → 「あなたの90日は今日から始まる」系の一言で締める
- **結論まで無料で見せる**（X教科書は戦略の結論「毎日・長文・有益」を無料部分で言い切る）。有料は「どうやるか」の実物（プロンプト・実測データ・手順）
- → うちの構成案の裁定「作る・比べるは無料で出し惜しみしない／テンプレと申請実務だけ有料」と完全に同型。**課金線は第3章の途中でなく、結論を言い切った直後・実物（テンプレ/全手順）の直前**が定石

## 4. 教材本体の型

- 章末に必ず「今日からやること」（3個まで）＋章の1行サマリ
- 「はじめに: この教材の歩き方」で読む順を指定（急ぐ人はどこへ直行か）
- 見出しは宣言型・体言止め（例の型: 「〜しか残らなかった」「喋れば、〜できる」）
- 更新履歴を冒頭に置き「生きている教材」を明示。追記アップデートを約束（Brainは更新がそのままページに反映される仕様）
- 免責は毎回入れる（成果保証しない・制度は変わる・最新は公式で確認）

## 5. 特典・導線の設計（Brainの実務仕様の観察込み）

- **購入者通信（メール登録）が特典受け取りの入口** = Brain購入者をメールリストへ吸い上げる設計。3本とも共通
  - → うちはSubstack一本の裁定なので「購入者はSubstack登録が特典受け取りの入口」に写像できる
- AI読み込みライセンス（購入者限定で教材全文をAIに読ませてOK化・個人利用限定・再配布禁止）が最新の定番特典
  - → チャットボット教材と相性が良すぎる（教材＋テンプレをAIに読ませて「自社版を一緒に作る」体験）。darari裁定待ちの特典候補
- Brainページ仕様の観察: 目次は自動生成で全見出しが並ぶ（目次自体が営業になる）／無料・有料エリアの境界が引ける／レビュー・アフィリ報酬率の設定あり（明鏡は50%）／部数マイルストーンで値上げ運用（「2,000部で1,980円に」等、必ず実施と明記=事実ベースの限定）
- 外部の学習サイト・Discordへの誘導も定番だが、うちはMVPでは追わない（Substack導線一本）

## 6. ダラリーヌ教材への適用メモ（構成案v0への反映）

- 文体: **darariの「ぼく」文体のまま**、改行リズム（1文1〜2行・空行多め）とテンポだけBrain仕様に
- 販売ページ冒頭: 名乗り＋現在地（製造業のAI活用推進責任者／Botを実際に公開済み／月0円は実測）→「動いてる忍者に触ってみてください」を最初に置く（実演を実物で置き換えられるのはうちの強み）
- 課金線: 「月0円で作れる」の結論と全体手順は無料で言い切る → テンプレ実物・法令/申請の実務から有料
- 各章末に「今日からやること」を追加（フレームS9の「次の一歩1つ」と統合。ただし3個までの型に合わせるか1個に絞るかはdarari裁定）
- 全数字に時点明記（「2026年8月実測」）。誠実性制約（検証実況・置き換え未実施）は「正直に書きます」の型で書くと自然に守れる
- 免責: 法的助言でない＋「AI申請の決まりが社内にあるならそれに従う」（RULES.md C3）を冒頭と法令章の両方に

## 7. 未確認事項（入稿時にdarari立ち会いで確認）
