# AI臭チェック だらリーヌ版（2026-08-18制定）

出典: darari支給の参考記事（@ysk_motoyama「AIっぽい文章表現大全」2026-02-03）を、
このリポの家風（だらリーヌ文体・Web記事・機械検査）に合わせて翻案したもの。
**記事を書いたら公開前に必ずこの表で自己検査する。** 機械で拾える分は ng-rules.json に落とし済み。

## このリポでは「AI臭」扱いしないもの（先に確認）

参考記事はプレーン文章向け。うちはWebサイトなので、次は**家風としてOK**:

- `##`見出し・`**太字**`・箇条書き（サイトが正しく描画する。構造はむしろ必須）
- 読者の心の声の「」先取り（ペルソナの型。_template.md ①）
- 用語の（）即解説（darari裁定の注釈方式。ただし1文に2個以上詰めない）
- 特典プロンプト内のMarkdown構造（E14。プロンプトはむしろ構造化する）

## 検査表（6分類）

### ① 記号のAI臭 → ほぼ機械検査済み

| パターン | 判定 | 検査 |
|---|---|---|
| 「： 」全角コロン+半角スペース | 禁止 | NG-011 (error) |
| ／での概念並列（例: 目的／背景／結論） | 原則禁止。・か文で書く | NG-012 (warn) |
| ——での言い換え接続・挟み込み | 禁止 | NG-004 (error)・F1 |
| 「」の切り出しすぎ／「」内の『』 | 多用注意。定義っぽい括りは文脈に溶かす。心の声とセリフ引用はOK | 目視 |
| （）補足しすぎ・（）内での責任回避 | 用語解説1回はOK。逃げ込みは禁止 | 目視 |

### ② リズムのAI臭

| パターン | 直し方 | 検査 |
|---|---|---|
| 同じ語尾4連続 | 体言止め・問いかけ・独り言を混ぜる | DOC-001 (error) |
| 順接接続詞の多用（さらに・また・したがって・そのため・結果として） | 順接は削っても伝わる。1画面に1個まで | 目視 |
| 温度が一定（重要も補足も同じテンション） | サビを作る。大事な1文だけ太字＋短文、補足は淡く | 目視 |
| 段落の閉じ方が毎回同じ（〜です。で整い続ける） | 長短を混ぜる。言い切りっぱなしで次へ行く段落を作る | 目視 |
| not A but B 構文の連発（〜ではありません。〜です。） | 1記事1回まで。2回目からはBだけ言い切る | 目視 |

### ③ 説明書のAI臭

| パターン | 直し方 | 検査 |
|---|---|---|
| 「先に結論を言います」「結論から言うと」の定型 | 前置きせず結論そのものを最初の文にする（E13は維持。宣言だけ削る） | NG-013 (warn) |
| 構造の宣言（以下の3つの観点から／それぞれ順に見ていきましょう） | 見出しに任せて削る | NG-014 (warn) |
| 「ステップ1：」ラベルの機械感 | 使うなら見出しに。本文中の「ステップ： 」ラベル列挙はしない | 目視 |
| 丁寧な受け止めから始まる長い前置き | いきなり本文（F3） | NG-010 (warn) |

### ④ 事なかれのAI臭 → スタンスを取る（D4と同根）

| パターン | 直し方 | 検査 |
|---|---|---|
| 保険の枕詞（一概には・状況によっては・場合もあります） | 削って言い切る | NG-002 (error) |
| ケースバイケースです・中立の装い（賛否が分かれます） | イチオシを言う。会社差の話はD6の「うちではこう判断した」形で | 目視 |
| 弱い否定（あまり推奨されません・注意が必要です） | 「やめてください」「やらない」と言い切る | NG-013 (warn) |

### ⑤ 抽象語・万能語のAI臭

| パターン | 直し方 | 検査 |
|---|---|---|
| 本質・最適化・価値を最大化・非常に重要・大きなメリット | 動詞中心の具体に置換。「何がどうなるか」を書く（D7: 言い切りには根拠） | NG-013 (warn) |
| 頭に絵が浮かばない抽象説明 | 実物・実数・実画面に置き換える（E5/E6） | 目視 |

### ⑥ 変な比喩 → 機械検査済み

地図・羅針盤・土台・柱・筋トレ・DNA・両輪・潤滑油・エンジン・スパイス・レシピ（NG-005/006）。
参考記事の追加分: 栄養・仕様書・設計書も比喩としては使わない（実物のREQUESTS.md等を指す文字通りの用途はOK）。

## リライト頼み方（サブエージェント・AIに直させるとき）

```
# 役割
あなたは日本語の編集者です。下の記事から「AIっぽさ」だけを取り除いてください。
意味・事実・数字・固有名詞・リンクは一切変えないこと。

# このサイトの家風（消してはいけないもの）
- ## 見出し・**太字**・箇条書き・特典プロンプトのコードブロックは残す
- 読者の心の声の「」先取り、（）での用語解説（1文1個まで）は残す
- 一人称「ぼく」、だらリーヌの熱と「！」は残す

# 消すもの
- 「： 」（全角コロン+半角スペース）、／での並列、——
- 「先に結論を言います」等の結論前置き。結論そのものを最初の文に
- 構造の宣言（以下の3つの観点から／順に見ていきましょう）
- 保険の枕詞と弱い否定。スタンスを言い切る
- 本質・最適化・非常に重要などの万能語。動詞中心の具体に
- 同じ語尾の連続、順接接続詞の連打、not A but B構文の2回目以降
- 段落ごとにきれいに閉じるまとめ癖。長短を混ぜてリズムを崩す

# 出力
- 書き換え後の記事全文のみ。分量は元の±20%以内
```
