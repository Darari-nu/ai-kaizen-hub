「AIの練習をしたい。でも、手元にある題材が仕事のデータしかない」

AIを触ってみたい気持ちはある。

でも、会社のデータを入れていいのかは分からない。

調べるのも面倒。間違えたら怖い。

で、何も入れずにそっと閉じる。この流れ、心当たりありません？

こんにちは、だらリーヌです！

ぼくはいま、製造部門でAI活用の推進を担当しています。前職は全社のAIガバナンス（AIを安全に使うための決まりごと一式）を作る側でした。

記事の最後に、あなたの業務の様式名を入れるだけで練習用データ一式を作れるコピペプロンプトを置いておきます。持って帰ってください。

## ぼくの練習の初日は、本物のメモでした

推進担当と名乗りましたが、ぼくのAI練習の始まりは、本物のメモです。

前職のころ、会社のPCで書いたメモを自分宛てメールで飛ばして、スマホの個人ChatGPTにコピペして相談していました。

機密は入れていません。ただ、「これは機密じゃない」と判断した根拠は、ぼくの勘だけ。

この話は[前の記事](/articles/014-nyuuryoku-handan/)でも白状しました。

いま思うと、あれは練習ですらリスクを背負う、いちばん下手なやり方です。

わかります。手元に題材が仕事のデータしかないと、ああなるんですよね。

## 言い切ります。練習に本物は要りません

**AIの練習に、本物の業務データは要りません。先に「全部ニセモノの練習用データ」を作ればいいんです。**

品番も、顧客名も、数字も、ぜんぶ架空。型だけ本物っぽく。

これなら機密の心配なしに、業務とほぼ同じ形の練習ができます。

先にニセモノを作る発想があれば、勘に頼る場面そのものが消えます。あのころのヒヤヒヤは要らなかったわけです。

なお、あなたの会社にAI利用のルールがあるなら、そちらが最優先。この記事のワザも、そのルールの範囲内でやってください。

## なぜ「本物で練習」は怖いのか

本物の業務データには、機密が普通に乗っています。

取引先の名前、原価、個人名。

だから本物を入れるときは、毎回「何を」×「どのAIに」の判断が要ります。この判断のやり方は[会議録、そのままAIに入れてません？](/articles/014-nyuuryoku-handan/)に書きました。

問題は、練習の段階でこの判断を毎回やるのは重すぎることです。

判断に自信が持てないから、触らない。触らないから、上達しない。

だったら、判断そのものが要らないデータで練習すればいい。

それが練習用のダミーデータ、つまり全部ニセモノのデータです。

型（項目立てや文の雰囲気）は本物っぽく。中身の品番・顧客名・数値は、ぜんぶ架空。

様式が社外秘でない範囲なら、会社の情報がひとつも入っていないので、機密を入れられないAIでも練習に使えます。

## 見本をどうぞ。架空の不良報告書です

実はこのサイトで、機密を入れずにAIを使う工夫はすでに2回登場しています。

1つ目はダミー議事録。架空の会議メモを3分ででっちあげて、議事録プロンプトの練習台にする話です。[議事録、清書するのやめました](/articles/017-gijiroku/)に書きました。

2つ目は固有名詞の抽象化。こちらは本物から機密を抜くワザで、今日のは最初から全部ニセモノを作るワザ。並べて使う関係です。

そして今日が3つ目。**架空の不良報告書を作って、分類と傾向分析を練習する**です。

見本を1枚どうぞ。記事に何度か登場している[架空企業ダラリ重工業](/company/)の品質保証課に、不良報告書を起票してもらいました。

```
不良報告書　No. DH-Q-0847

発生日     : 2026年7月28日
発見工程   : 第2工場 塗装ライン（目視検査）
品番／品名 : DK-3310 ／ 減速機カバー
納入先     : ダラリ精工株式会社
不良内容   : 塗装面にブツ（異物の混入）。同一ロットに集中
不良数     : 42個 ／ 検査数 600個
応急処置   : 当該ロット全数を再検査、不良品は再塗装
原因       : 調査中（塗料ろ過フィルタの交換記録が前週から空欄）
起票者     : 品質保証課 世良
```

もちろん、ぜんぶウソです。

品番も納入先も数字も、この記事のために作った架空のもの。でも型は、製造業の人なら見覚えのある形に寄せてあります。

## 手順は3ステップ

見本を1枚作って終わりではなく、AIに10件量産させます。

そのうえで、こう頼むんです。

「この10件を不良の種類ごとに分類して、気になる傾向があれば教えてください」

はい、これで「報告書の山をAIに分析させる」という、本物でやりたい業務そのものの練習が始まります。

1. **AIに練習データを10件作らせる。** 末尾のプロンプトで、分析の練習になる「偏り」と「答え」つきで作らせます
2. **そのデータで、本物でやりたい仕事をAIに頼む。** 分類、傾向分析、要約、なんでも
3. **AIの出力と「答え」を突き合わせる。** 仕込んだ偏りに気づけたか、書いていないことを勝手に足していないかを確認する

3ステップ目が、ダミーならではのうまみです。

本物のデータには「正解」がありません。だからAIの分析が当たっているのか、それらしいだけなのか、確かめようがない。

ニセモノなら、答えを先に仕込めます。

答え合わせができるから、AIの実力とクセを安全な場所で測れるわけです。

## この方法が通用する条件

ダミーなら何をしてもいい、とまでは言いません。

帳票の項目立てそのものがノウハウで、様式ごと社外秘という会社もあります。

だからここでも、社内ルールが先。ぼく自身は「項目は世間一般の様式に寄せる。実在の社内帳票を丸写ししない」を自分の線にしています。

## 聞かれがちな質問

**Q1. ダミーを作る時間がもったいなくない？**

作るのはAIで、あなたは様式名を入れるだけです。

それに、「うちの帳票はどんな項目だったっけ」と思い出す作業自体が、業務の棚卸しになります。

練習が終わったあと、プロンプトは本物にそのまま流用できます。作った時間は捨てになりません。

**Q2. どこまで本物に似せていいの？**

項目の型は、世間一般の様式まで。実在の社内帳票の丸写しはやめましょう。

品番・顧客名・数値は、必ず架空にしてください。

迷ったら、「このダミー、社外の人にそのまま見せられるか」と自分に聞くこと。

見せられない箇所が残っていたら、そこにまだ本物が混ざっています。

**Q3. 練習の成果は、どう本物につなげるの？**

持っていくのはプロンプトと、AIのクセの知識です。データは持っていきません。

本物を入れる段になったら、「何を」×「どのAIに」の[判断](/articles/014-nyuuryoku-handan/)に戻ってください。

会社契約のAIを正面から通したくなったら、ぼくの[申請の実録](/articles/004-claude-team/)をどうぞ。

**Q4. ダミーなら、会社のPCで勝手にAIを使っていい？**

それは別の問題で、ダメです。

データの中身がニセモノかどうかとは別に、「そのAIを会社で使っていいか」のルールがあります。

会社で許可されたAIでやってください。まだ無いなら、[会社が不安な3点の押さえ方](/articles/002-ai-rules-starter/)から。

会社の情報がゼロのダミー練習は、個人の学習として自分の環境で始めやすい。そういう順番です。

## 今日の一歩

**下のプロンプトに、あなたの業務の様式名をひとつ入れて、AIに練習用データを作らせてみてください。**

不良報告書でも、日報でも、出張精算書でも、問い合わせメールでもいいです。

## 特典: 練習用ダミーデータをつくるプロンプト

このプロンプトを、そのまま使えます。様式名の1行だけ、あなたの業務に差し替えてください。

```
# 役割
あなたは練習用ダミーデータの作成係です。
次の様式の「全部架空の練習データ」を10件作ってください。

# 様式名
- （ここにあなたの業務の様式名を入れる。例: 不良報告書、出張精算書、問い合わせメール）

# 条件
- 会社名・人名・製品名・品番・金額・日付は、すべて架空にしてください。実在の企業名・製品名は使わないでください
- 項目立ては、その様式の世間一般の形にしてください
- 10件のどこかに、分析の練習になる「偏り」をわざと仕込んでください
  （例: 特定の工程に不良が集中している、特定の月だけ金額が跳ねている）

# 出力
- 架空の練習データ10件
- 最後に、仕込んだ偏りを「答え」としてまとめて書いてください
```

10件できたら、「種類ごとに分類して、気になる傾向を教えてください」と頼めば練習開始です。

答え合わせまでやると、AIの得意と、しれっと話を作るクセの両方が見えてきます。

「怖いから触らない」は、今日で終わりにしましょう！
