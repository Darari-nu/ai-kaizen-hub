# 05-2 社内AI規程の公開事例

**用途**: 「生成AIの利用ガイドラインを公開している会社は、実はけっこうあります」の**中身をリンク集として実体化**する台帳。
読者がそのまま自社の稟議に添付できる状態にすることが目標。

**🔴 二次利用の可否について（最重要）**
本台帳の「二次利用」欄は、**公開元のページ／文書に利用条件の明記があった場合のみ「許諾あり」**と書く。
明記がなければ「**記載なし**」。記載なし＝転載してよい、ではない。**そのまま社内文書に流用する前に必ず公開元に確認すること。**

取得日は全件 2026-08-15。

**収録件数**（2026-08-15 第4次調査で更新）: 公開元 **17者**（企業5・自治体5・国/独法3・業界団体1・大学3）／関連文書 26本。
🔴URL未検証は **0者**（パナソニック コネクトは配布URLに到達し、PDF本体を取得した）。
第3次で増えたのは **福岡県『生成AI庁内利活用ガイドライン』第2.2版（本体18ページ取得済）** と
**横須賀市『ChatGPT活用実証結果報告』（本体60ページ取得済）**。
第4次で増えたのは **筑波技術大学『生成ＡＩの使用に関する方針』（全文HTML取得済）** と
**東北大学『ChatGPT等の生成系AI利用に関する留意事項』教員向け・学生向け2本（全文HTML取得済）**。
第4次でさらに **デジタル庁DS-920に第2.0版（2026年6月12日）が出ていることを確認**し、本文の当該項を更新した。

**二次利用が明記で許諾されているのは 7本**（前回4本から+3本）。内訳:
デジタル庁2本＝公共データ利用規約PDL1.0／総務省2本＝公共データ利用規約（第1.0版）／
**神戸市2本＝神戸市ウェブサイト利用規約（出典記載を条件に自由利用可・商用可）**／JDLA1本＝改変を明示的に容認。
これとは別に**東北大学2本が「条件付き許諾」**（2026-08-15 第4次で確認。**「大学やその他の教育機関において同様の注意喚起を発出する場合」に限り**、
挿絵を除き複製・改変可・出典明記も不要と明記。**用途が教育機関限定なので決定A（有料教材利用）の7本には数えない**）。
**民間企業は引き続き0件**（富士通・X-Tech5・SmartHR・サイバーエージェント・パナソニック コネクトのいずれも許諾の記載なし）。
**東京都は「許諾なし」ではなく「明示的に不可」**と判明（サイトポリシーに無断複製・転用不可と明記）。

  該当＝富士通／X-Tech5／SmartHR／サイバーエージェント／パナソニック コネクト。

- 神戸市『神戸市生成AIの利用ガイドライン』第1.2版を**雛形として使う。さらに解説記事も書く**（両方やる）。
- ⚠️ **必ず併記する注意**: 神戸市ウェブサイト利用規約は出典記載を条件に商用利用まで認めているが、
  同規約2)に「第三者が著作権その他の権利を有している場合があります…利用者の責任で、当該第三者から利用の許諾を得てください」とある。
  **本PDFの作成者（Author）欄が `JDLA` である事実と併せると、この条項2)に当たる可能性を排除できない。**
  この注意は削除せず、雛形として配る場合は神戸市への事前確認を前提にすること。
