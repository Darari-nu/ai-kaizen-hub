# §3. 「無料」の罠（記事にそのまま使える）

**"無料"と書いてあっても実際には無料でないもの。全件一次で確認済み。**

| 対象 | 実態 |
|---|---|
| **Google AI プロフェッショナル認定証** | **月49米ドルの有料**（一次に「日本でのサブスクリプション料金は、月額 49 米ドルです。」）。無料は日本リスキリングコンソーシアム経由の**先着順・数量限定**枠のみ |
| **Google Skills** | **クレジット消費制**（Gemini Code Assist=5／Gemini CLI=3／MCP×ADK=7）。月35クレジットは別途 Google Developer Program 登録が必要。「no credits required」明記は**7本だけ** |
| **JDLA AI For Everyone** | 2025年8月に無料聴講廃止 → **$49**。見出しは「無料」のまま |
| **Gemini API** | 料金ページに "Free of charge" とあっても **RPD=0 で無料枠では使えないモデルがある**（2.5 Pro／3.1 Pro／Nano Banana／Veo 3／Lyria 3）→ [07-1 A-3-1](../07_Bot自作ルート/07-1_自作の技術ルートと実費.md) |
| **Anthropic API** | 評価ティアのレート制限は設定されているが、**クレジット残高$0では叩けない**＝実質的な無料枠なし → [07-1 A-1-1](../07_Bot自作ルート/07-1_自作の技術ルートと実費.md) |
| **Vercel Hobby** | 一次に**「非商用・個人利用のみ」**と明記。会社では使えない |
| **東大松尾研 AXエバンジェリスト講座** | 無料だが**社会人は個人申込不可・1団体10名以上**。ひとりの会社員は入れない |
| **AVILEN 製造業ウェビナー** | 動画視聴に**フォーム必須＝実質法人申込** |

# §7. 【読み取り】アドバンテージ

> ⚠️ **ここから下は事実ではなく解釈。** §1〜§6の事実から収録者（Opus）が読み取ったもの。
> **最終判断はFableとdarariの領分**であり、この節を根拠として引用しないこと。

## 空いている席の座標

§6の集計を言い換えると:

- **製造業のことを書いている人は、自分の会社の話をしていない**（5件すべて他社取材）
- **自分の会社の話をしている人は、製造業にいない**（5件すべてIT企業）
- **その交差点は0件**

darariの旗「**製造業の中の人が、会社にAIを正規に申請→導入→使い倒す実況**」は、
この交差点そのものを指している。

## 4つの差別化軸（強い順）

| # | 軸 | 事実の裏付け |
|---|---|---|
| 1 | **自社実況 × 製造業** | 交差点0件（§6）。個人メディアも0件 |
| 2 | **現場の1人が申請を通す手順** | 「稟議」「社内申請」「情シス」の語が全ページで0件（§6）。あるのは上流の制度設計だけ |
| 3 | **品質保証** | ベンダー17件中0／資格11件中0／生成AI導入事例0（§4） |
| 4 | **既存の製造業教育基盤の空きスロット** | WEBee Campus 200本・カイゼンベース年間120万人に、AIが0件（§5） |

## 逆に、勝負してはいけないところ

| 領域 | 理由 |
|---|---|
| **AIの一般的な使い方・入門** | Microsoft Learn 367モジュール317.6時間、Udemy無料1,357件、明鏡83講座1,409回。**物量で勝てない** |
| **製品の操作解説** | ベンダーが公式で日本語・無料・更新継続。**構造的に勝てない** |
| **AI資格の対策** | ITパスポートは過去問全公開＋**IPAが二次利用の許諾・使用料不要と明記**。AI実装検定B級はYouTube41本で全公開。**すでに無料で完結している** |
| **経営層向けのAI戦略** | Microsoft「製造のリーダー向け」187分ほか、上流は埋まっている |

## 「有料で売ってよいもの」との整合

darari裁定（CLAUDE.md）: **有料で売ってよいのは座学でないもの＝一次体験の実話・テンプレ実物・時短**。
この調査はその裁定を裏付けている——**座学は無料で飽和しており、埋まっていないのは
「自社でやった実話」と「現場で通す手順」だけ**。両方とも座学ではない。

## 注意すべき前提の修正

- **「会社で使う」は空白ではない**（02-1: 8社が名指し済み）。空いているのは「会社で**通す**」（§6）
- **「会社で通す」も完全な空白ではない**（Microsoft Learnが日本語で387分を投入）。
  ただし性質が違う（製品導入の手順 vs 社内政治）

  ただし本調査で**4方向（スクール／ベンダー／資格／教育基盤）から独立に0件**が確認され、当初より裏付けは厚い
