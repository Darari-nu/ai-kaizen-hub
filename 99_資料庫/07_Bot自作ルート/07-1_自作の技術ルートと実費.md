### 参考A: 構造的な注意点（分類外・数値の解釈に必要な条件）

1. **通貨がバラバラ**。A層・C層・D層は主にUSD、B層のLINE/Slackは日本円、n8nは**ユーロ（€）**。
   SaaS側（01-1）は日本円中心。円換算して並べる場合は**為替レートと換算日を明記する必要がある**（本ファイルでは換算していない）。
2. **税表記が取れないものが多い**。LINE（税別と明記）以外は、Slack・Make・Zapier等で税表記の記載を確認できず。
3. **無料枠の「リセット単位」が層ごとに違う**。Cloudflare Workers は**日次**（100,000/日）、
   Cloud Run・Lambda・Pinecone・Make・Zapier は**月次**。同じ「無料」でも枯渇の仕方が違う。
4. **自作ルートは1サービスの料金では完結しない**。少なくとも A（LLM API）＋ B（窓口）＋ C（実行環境）の3層、
   RAGを足すなら D（ベクトルDB＋Embedding）の4層が積み上がる。
   さらに Cloud Run は Cloud Build / Artifact Registry / Eventarc が別課金、
   Azure Bot Service は App Services / Application Insights が別課金と**一次に明記がある**。
   **Anthropic の Claude を使う場合、embedding は必ず別ベンダーになる**（自社モデルを提供していないと明文がある → D-2-1）。

4-2. **「無料枠がある」と「実際に無料で叩ける」は別**。この台帳で3件、同じ形のズレが出ている。
   ①Gemini: 料金ページに "Free of charge" と書いてあるモデルでも **RPD=0 で使えないものがある**（A-3-1）。
   ②Anthropic: 「新規ユーザーに少額の無料クレジット」の表記があるが、**本人アカウントは残高$0.00**（A-1-1）。
   ③OpenAI: 利用ティア表に **"Free" ティアがある**が、モデル別の free 行があるのは**96モデル中9モデルのみ**で、
   **テキスト生成のチャット用モデルには free 行がない**（A-2-3・A-2-4）。
   記事に書くときは、**表記の有無ではなく「実際に叩ける回数」の出典があるかどうか**で区別すること。

4-3. **無料枠には「使わないと消える」型がある**。上限に達して止まるのとは別の止まり方。
   Supabase Free = **1週間の無操作でプロジェクト一時停止**／Qdrant Free = **未使用1週間で一時停止・4週間で削除**／
   Render Free = **15分無通信でスピンダウン**（復帰約1分）。
   社内Botのように**アクセスが散発的な用途**では、上限より先にこちらに当たる可能性がある（＝条件の併記が要る）。

4-4. **段階（Tier）逓減に注意**。AWS Lambda の実行時間は**3段階の逓減制**で、料金ページに出ている単価は Tier-1 のもの
   （x86: 最初の60億GB-秒まで $0.0000166667／ARM: 最初の75億GB-秒まで $0.0000133334 → C-4-1）。
   LINE の追加メッセージも15段階、Make.com も19段階。**「単価」を1つだけ引いて掛け算すると、条件が抜ける。**
5. **トークン単価から月額を出すには「1問あたりのトークン数」が要る**。本ファイルには**その実測値がない**。
   → darari本人がダラリ重工業Botで実測するのが唯一の埋め方（🟠本人待ち）。
   日本語1トークンあたりの文字数も、3社とも一次に記載がない（Anthropicは英語基準の目安のみ）。
