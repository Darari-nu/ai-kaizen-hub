# 画像生成スキル（みどり脳準拠・このリポ限定）

このリポジトリで画像を作るときの固定手順。**プロンプトを自己流で書かない。必ずみどり脳の型で組む**（2026-08-05 darari指示）。

## STEP 1: みどり脳を読む

正本: `~/Claudecode/260307_2nd-Brain/30_統合脳セット_20260531/30_みどり脳/`

| いつ | 読むノート |
|---|---|
| 毎回必読 | `prompt/seven-elements.md`（7要素の型・中核） |
| 量産するとき | `prompt/gacha-prompt.md`（固定×ランダム）、`recipe/_moc.md` |
| 品質が悪いとき | `quality/_moc.md`（AIっぽさ4分類・ガビガビ対策） |
| 完成物の種類別 | `creatives/_moc.md`（サムネ・図解・アイソメ・X画像など） |
| 色の指定に迷ったら | `prompt/color-code.md`（カラーコードと引っ張られ問題） |

## STEP 2: 7要素でプロンプトを組む

**①用途**（置く場所と比率まで。例: HPヒーロー 縦4:5）→ **②読者**（JTC勤めの非エンジニア）→ **③主役**（1つに絞る）→ **④文字**（原則「入れない」。文字はサイト側で組む）→ **⑤構図**（視線の流れ）→ **⑥作風**（下のカラーコードを明示）→ **⑦NG**（先に外す）

用途から書き始めると残りが芋づる式に決まる。失敗したら「どの要素が曖昧か」に戻る。

このサイトの⑥作風トークン:
```
紙白 #FBFAF7 / 墨 #1C1B18 / 鼠 #6E6A61 / 罫線 #E3E0D8 / 朱 #C73E2E（アクセントは朱1色だけ）
白ベース・エディトリアル。製造業×書類の世界観
```

このサイトの⑦共通NG:
```
文字・ロゴ・記号を画像に入れない / 人物を出さない / 派手な背景 / 実在製品・実在企業
```

## STEP 3: Codex CLIで生成する

```bash
codex exec --skip-git-repo-check -C "/Volumes/DevSSD/Vibe_Website/260805_Darari-nu_HP" \
  --sandbox workspace-write \
  "画像生成ツールで次の画像を1枚生成して、public/images/<名前>.png に保存してください。既存ファイルは上書きしないこと。
   <7要素で組んだプロンプト（画像内容は英語推奨）>
   アスペクト比: <①で決めた比率>。文字は絶対に入れないこと。"
```

- タイムアウトは長めに（300000ms）
- Midjourney（本人手作業・`--sref`でシリーズ統一）に切り替える場合は、7要素をMidjourney書式に変換して本人に渡す

## STEP 4: 検品（生成後に必ず）

1. Readツールで画像を実際に見る
2. チェック: 文字・ロゴが混入していないか／主役が1つか／朱以外の派手な色が出ていないか／AIっぽい破綻がないか
3. NGなら7要素のどこが曖昧だったかを特定して再生成（`quality/_moc.md`参照）

## 置き場所の規約

- ヒーロー: `public/images/hero.png`（4:5。消すとSVG線画にフォールバック）
- OGP: `public/images/og-default.png`（16:9）
- 記事用: `public/images/articles/<slug>.png`

## 記事ヒーローは親レシピで統一

**記事には必ずヒーロー画像を付ける。** スタイルは同ディレクトリの `article-hero-recipe.md`（親レシピ「朱一点の静物」）に固定。子レシピでは{SUBJECT}＝記事の主役だけ差し替える。生成したら台帳に追記し、記事frontmatterの `ogImage` にパスを書く。
