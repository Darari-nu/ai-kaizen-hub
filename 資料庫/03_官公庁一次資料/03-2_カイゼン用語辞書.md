# 03-2 カイゼン用語辞書

AIの話を製造現場の言葉に翻訳するときの**語彙帳**。
「用語 / 一文の定義 / 出典URL / 一次二次の別」だけを置く。**推測で定義は書かない。**

## 収録ルール（規約の適用）

- 定義は**出典ページの本文から確認できた内容だけ**を要約したもの。原文の丸写しはしない
- **一次** = その概念の本家（トヨタ自動車）・公的機関（厚労省・中小機構・IPA・農水省・JICA）・業界団体（JIPM・日科技連）の公開物
- 出典が取れなかった用語は**載せず**、末尾の「⬛非公開」に名前だけ置いた
- 収録した21項目は**すべて一次**。二次のみの項目はゼロ

## 取得環境メモ（次に更新する人へ）

- 厚労省「職場のあんぜんサイト」（`anzeninfo.mhlw.go.jp`）は**Shift_JIS（CP932）**。素で取ると文字化けし、**まったく別の用語の内容が返ってくる**（実際に「危険予知」を引いたつもりが「三六協定」の本文が返る事故が起きた）。必ず `iconv -f CP932 -t UTF-8` を通し、**ページタイトルで用語名を照合してから**使うこと
- `global.toyota` は User-Agent なしだと403。ブラウザUAを付ける
- 本ファイルのURLは全件 HTTP 200 を確認済み。上記4サイトは本文まで再照合した
- 2026-08-15 追試: あんぜんサイトのKYTページを **iconv＋`<title>`照合**（「職場のあんぜんサイト：危険予知訓練（ＫＹＴ）」）の手順で取り直し、**4ラウンド法の3R・4Rを回収**した（下記§4）。この手順は事故なく回った

### 🔓 JIS本文の取り方（2026-08-15 に手順を確立。これがこのファイルの最大の武器）

JISは有償規格だが、**JISC（日本産業標準調査会）の「音声PDF」はログイン不要**でテキスト入りPDFが落ちる。
curlだけで完結する。UAは付けること。

1. **規格番号で検索** → `POST https://www.jisc.go.jp/app/jis/general/GnrJISNumberNameSearchList?show`（`jisStdNo=Z8141`）
2. 返ってきたHTMLから `setHidden('jisStdId','2100045848')` を拾う
3. **詳細画面** → 同URLに `?toGnrJISStandardDetailList`（`jisStdId` と `jisStdNo`）。
   ここに**規格名称・主務大臣・制定年月日・最新改正年月日**があり、`setHidden('selectFileId','…')` が音声PDFのID
4. **本体DL** → `POST https://www.jisc.go.jp/app/jis/general/GnrJISStandardDetailList?downloadSound`（`jisStdId`・`jisStdNo`・`selectFileId`）
5. `pdftotext -enc UTF-8` で抽出。**全角スペースが挟まるので `re.sub(r'\s+','',text)` で潰してから検索**しないと語がヒットしない

**「どのJISがその語を使っているか」は単語検索で数えられる**:
`POST https://www.jisc.go.jp/app/jis/general/GnrJISUseWordSearchList?show`（`keyWord=ムダ`）。
実際にこれで「ムダ」を引き、Q9024・Q9028・Z8141の3件に絞り込めた（＝今回の発見の入口）。

⚠️ **図表はテキスト抽出すると順序がバラバラになる。** 3Mの模式図はこれで危うく取り違えるところだった。
**`pdftoppm -f N -l N -r 130 -png` でページを画像化して目視確認**してから記録すること（本ファイル§2の3M表は目視確認済み）。

### 🔧 3M（ムリ・ムダ・ムラ）― 一次の定義と模式図（厚生労働省）

本人が「よく聞く」と証言していた3ムに、**厚労省の一次定義がある**。
ただし**出典は介護分野のガイドライン**であって製造業向け文書ではない。**引くときはこの出所を隠さないこと。**

| 要素 | 概要（出典の「概念図/概要」欄） | 模式図での定義 |
|---|---|---|
| **ムリ** | 設備や人材の**心身への過度の負担** | 目的に対して手段が**下回る**こと（目的＞手段） |
| **ムダ** | **省力化できる業務** | 目的に対して手段が**上回る**こと（目的＜手段） |
| **ムラ** | 人・仕事量の**負荷のばらつき** | 目的に対して手段が下回ったり上回ったりすること（目的＞手段 or 目的＜手段） |

**この3Mの並びは「ムリ→ムダ→ムラ」**（出典の表の順）。本人の口ぐせ「ムリ、ムラ、ムダ」とは順が違う。

**同ガイドラインが3Mを使っている文脈（本文より）**: 7つの取組の2番目「業務の明確化と役割分担」の効果を
「ムリ・ムダ・ムラ（3M）を削減してマスターラインを再構築できる」と定義し、
3Mの探し方として「特定の職員への業務の偏り（ムリ・ムラ）」「昔から実施しているが本来は不要な業務（ムダ）」を例示している。
また改善活動の手順2「見える化」を、**誰がどの業務にどれだけ時間をかけているかを見える化して3Mを明らかにする**工程と位置づけている。

https://www.mhlw.go.jp/content/12300000/Seisansei_kyotaku_Guide.pdf （全154ページ・実測）。

| **取付具（fixture）** | **JIS B 3000:2020「FA-用語」2035** | 加工物を工作機械・作業台に正しく取り付け、容易に取り外せるようにした支持具 |
| 上位語＝**工具** | **JIS Z 8141:2022「生産管理用語」1205** の注釈1 | 「工具類には切削工具のほかに**ジグ、取付具**、型、限界ゲージ及び各種作業用具を含む」 |

**jig と fixture の使い分けも公的に定義されている**: **ジグ＝「工具」を導く／取付具＝「ワーク」を据える**。
