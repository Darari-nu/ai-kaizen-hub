# 03-2 カイゼン用語辞書

AIの話を製造現場の言葉に翻訳するときの**語彙帳**。
「用語 / 一文の定義 / 出典URL / 一次二次の別」だけを置く。**推測で定義は書かない。**

## 収録ルール（規約の適用）

- 定義は**出典ページの本文から確認できた内容だけ**を要約したもの。原文の丸写しはしない
- **一次** = その概念の本家（トヨタ自動車）・公的機関（厚労省・中小機構・IPA・農水省・JICA）・業界団体（JIPM・日科技連）の公開物
- 出典が取れなかった用語は**載せず**、末尾の「⬛非公開」に名前だけ置いた
- 収録した21項目は**すべて一次**。二次のみの項目はゼロ

### 🔧 ECRS の詳細（出典PDF本文より。AIの話に直結するので全部残す）

| 順番 | 原則 | 意味と着眼点 |
|---|---|---|
| 1st | **E（Eliminate）省略** | やめられないか？ 本当にこれが必要なのかを問う。運搬、向き変え、頻繁な検査など価値を生まない動作を削減する |
| 2nd | **C（Combine）統合** | 一緒にできないか？ 他の作業と同時進行・統合できないかを考える（例: 加工と同時に検査） |
| 3rd | **R（Rearrange）変更** | 入れ替えられないか？ 作業の順序・場所・人を変更できないかを考える |
| 4th | **S（Simplify）単純** | 簡単にできないか？ 上記3つを検討した上で、作業をより楽に・簡単にできないか考える（例: 自動化） |

**出典PDFが「重要」として明記していること**: 改善は必ず E→C→R→S の順で行う必要がある。EやCをせずにいきなりS（自動化・デジタル化）をやると、**やめられるムダをそのまま自動化してしまい、効果的な投資にならない**、と同資料は述べている。

出典資料の書誌: 知識の講座「現場改善を進める第一歩」～現場カイゼンのためのIEと投資の意思決定を支援する経済性工学～／講師: 大阪工業大学 教授 皆川健多郎／全22ページ（実測）／発行年月は⬛非公開（PDF本文に記載がなく、発行元が明示していない。2026-08-15 再確認済み）

### 🔧 ヒヤリハットで出典が明記している運用上の要点（記事に効く）

- ヒヤリハットは報告する側にとっても受ける側にとっても名誉なことではない。だから**労働者を責めないという取決め**をし、それを実行しないと制度が長続きしない
- 作業手順書どおりにやらなかったことが原因でも、**手順書に無理があって守れなかった**のかもしれない。手順書見直しの良い機会と考えるべき

### 🔧 KYT基礎4ラウンド法（出典本文より、1R・2Rのみ確認済み）

| ラウンド | 内容 |
|---|---|
| 1R | **どんな危険がひそんでいるか** ― イラストシートの状況の中にひそむ危険を発見し、危険要因とその要因がひきおこす現象を想定して出し合い、チームのみんなで共有する |
| 2R | **これが危険のポイント** ― 発見した危険のうち重要と思われるものに○印、さらにみんなの合意でしぼりこんで◎印とアンダーラインをつけ「危険のポイント」とし、指差し唱和で確認する |
| 3R | **あなたならどうする** ― ◎印をつけた危険のポイントを解決するにはどうしたらよいかを考え、具体的な対策案を出し合う |
| 4R | **私達はこうする** ― 対策の中からみんなの合意でしぼりこんで※印をつけ「重点実施項目」とし、それを実践するための「チーム行動目標」を設定し、指差し唱和で確認する |

由来（出典本文より）: もともと住友金属工業で開発され、中央労働災害防止協会が「問題解決4ラウンド法」と結びつけ、さらに旧国鉄の指差呼称を組み合わせた「KYT4ラウンド法」が標準とされている。
